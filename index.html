Twitch HLS Proxy
installation.

Userscript qui route les flux HLS de Twitch via plusieurs relais, avec fallback automatique, dashboard de statistiques (latence, bande passante estimée, temps de visionnage) et proxys personnalisables.

⬇ Installer le script
Nécessite une extension de gestion de userscripts — Tampermonkey ou Violentmonkey. Le lien ci-dessus l'ouvre directement dans l'invite d'installation de l'extension.
🔁
Fallback automatique
Bascule sur Twitch si tous les relais échouent.
📊
Dashboard complet
Classement des relais, streamers suivis, logs — dans un nouvel onglet.
🎬
Qualité en arrière-plan
Empêche Twitch de réduire la qualité quand l'onglet n'est pas visible.
⚙️
Proxys personnalisés
Ajoute, réordonne et teste tes propres relais.
